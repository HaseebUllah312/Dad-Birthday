# Happy Birthday, Dad — Saleem Mughal 🎂🎉

A special, authentic, interactive birthday tribute website created with love for **Saleem Mughal** by his son **Haseeb**.

## ✨ Features
- **Hero Avatar Portrait**: High-resolution portrait header celebrating Saleem Mughal.
- **Urdu Calligraphy**: Beautiful Urdu heading (*"والد محترم، آپ کو سالگرہ مبارک ہو"*).
- **Interactive Parchment Letter**: Clickable wax seal (`SM`) that unseals a heartfelt letter.
- **Polaroid Memory Gallery**: Features authentic family photos with lightbox modal preview.
- **Heartfelt Son's Wish**: Dedicated birthday wish card from Haseeb to Dad.
- **Interactive Birthday Cake**: Clickable candle blowout with smoke animation and celebratory chimes.
- **Ambient Music Player**: Background music toggle with fallback Web Audio API synth player.
- **Floating Petals Animation**: Canvas animation of marigold and rose petals drifting across the screen.
